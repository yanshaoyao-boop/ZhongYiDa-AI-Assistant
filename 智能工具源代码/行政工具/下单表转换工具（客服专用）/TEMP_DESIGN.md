# 下单表转换工具 (Excel Transformer) 设计方案

## 1. 核心架构与技术栈

我们将构建一个**纯前端**的 Web 应用程序，不需要后端服务器，这样最安全且响应最快。

* **框架**: Vue 3 + Vite (高性能前端框架)
* **UI 库**: Tailwind CSS (实现美观、现代的界面) + Headless UI (交互组件)
* **Excel 处理**: SheetJS (`xlsx` 库) - 业界标准的浏览器端 Excel 处理库
* **动画**: Framer Motion 或 CSS Transitions (实现流畅的过渡效果)

## 2. 详细交互流程

### 第一步：文件上传 (File Upload)

* **界面布局**: 屏幕中央分为左右两个巨大的拖拽区域。
  * **左侧 (源)**: "点击或拖拽上传 A 表格 (数据源)" - 蓝色主题。
  * **右侧 (目标)**: "点击或拖拽上传 B 或 C 表格 (目标模版)" - 绿色/紫色主题。
* **功能**: 上传后立即解析文件，读取特定行（A读取第11行，B读取16行，C读取17行）的表头以供后续使用。

### 第二步：字段映射 (Field Mapping)

* **界面布局**:
  * 上传成功后，下方滑出映射配置区。
  * 显示两列垂直排列的卡片，共 20 行。
  * **左列**: 下拉菜单显示 **A表格** 的所有列名（来源于第11行）。
  * **右列**: 下拉菜单显示 **B/C表格** 的所有列名（来源于16/17行）。
* **仓库代码逻辑**:
  * 界面顶部会自动显示从 A表格 M8 单元格读取到的“仓库代码”。
  * 用户可以确认这个代码将写入到 B表格(B3) 或 C表格(B5)。

### 第三步：模版管理 (Template Management)

* **操作**: 映射区顶部有一个工具栏。
  * [图标] **导出配置**: 将当前选好的 20 个对应关系保存为 JSON 文件。
  * [图标] **导入配置**: 选择之前的 JSON 文件，一键还原所有下拉菜单的选项。

### 第四步：生成与下载

* **预览**: (可选) 显示前 5 条数据的转换预览。
* **执行**: 点击巨大的“开始转换”按钮。
* **逻辑**: 程序读取 A 的数据，按照映射关系填入 B 或 C 的结构中，并将 M8 的值填入对应位置。
* **输出**: 浏览器自动下载生成好的新 Excel 文件。
