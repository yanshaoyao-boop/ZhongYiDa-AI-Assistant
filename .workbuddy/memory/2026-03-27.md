# 2026-03-27 工作日志

## 项目全面调研

今天完成了对"仲易达智能助手"项目的全面阅读和分析，核心发现：

### 项目架构
- **双前端**：Vue3 Web端 + Uni-app小程序端
- **后端**：FastAPI + SQLite + ChromaDB
- **AI**：豆包系列大模型(RAG + Vision)

### 三大AI模式
1. **全能助手(general)**：常规业务
2. **知识教练(coach)**：沉浸式对练培训
3. **专家指导(expert)**：深度策略拆解

### 核心服务
- `llm_client.py`：豆包API封装，流式输出
- `rag_service.py`：ChromaDB向量检索
- `quote_service.py`：多渠道报价解析(锦联/亿阳/星夜等)
- `address_service.py`：亚马逊仓库偏远识别
- `tracking_service.py`：Playwright爬虫轨迹查询
- `chat_intelligence.py`：意图分类/查询改写/文档重排

### 关键文件位置
- 后端入口：`backend/main.py`
- 核心聊天路由：`backend/routers/chat.py`
- Web前端主页：`frontend/src/views/ChatView.vue`
- 小程序：`frontend-uniapp/`
- 开发计划：`docs/plans/`

### 项目状态
- v1.1.0已完成
- 进行中的计划：后端聊天重构、小程序深度适配、管理台联调
