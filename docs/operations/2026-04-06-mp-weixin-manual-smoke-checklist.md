适用范围：`frontend-uniapp` 微信小程序版本  
执行时间：每次发版前、每次后端接口变更后

## 1. 前置准备

- [ ] 后端服务可用（测试环境或生产环境），并确认登录接口可访问
- [ ] 已执行并通过：
  - `npm run test:chat-page-bindings`
  - `npm run build:mp-weixin`
- [ ] 微信开发者工具已导入项目：`frontend-uniapp/dist/build/mp-weixin`
- [ ] 准备测试账号：

  - 管理员账号（用于后台跳转）

## 3. 通过判定

- [ ] 登录、聊天、通知、后台跳转 4 条主链路全部通过
- [ ] 无 P0/P1 问题（无法登录、无法聊天、页面白屏、关键按钮无响应）
- [ ] 可进入提审/发布流程

## 4. 常见失败快速排查

- 登录失败：优先检查后端地址、鉴权 token、登录接口状态码
- 聊天无响应：检查 `/api/chat/stream` 返回、网络超时、会话 token
- 通知为空：检查 `/api/notices/current`、`/api/notices/history` 接口
- 后台跳转失败：检查账号角色/权限字段和本地缓存权限同步
