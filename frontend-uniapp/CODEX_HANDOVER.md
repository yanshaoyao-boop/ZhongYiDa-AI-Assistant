# 小易智能助手 - 微信小程序迁移交接文档 (Handover to Codex)

## 1. 项目核心理念与定位

**小易智能助手** 是为“仲易达集团 (ZHONGYIDA GROUP)” 量身定制的高效 AI 工作台系统。

- **视觉控制**：我们追求**严谨、高效、专业**的企业级桌面工作台风格。设计上严格使用“白/浅灰底 + 蓝紫色主题键 (`#5c52e6`) + 深灰字”的经典扁平化配色。**绝对避免**花哨的移动端拟态、重的玻璃特效 (Glassmorphism) 或无意义的渐变色。PC 端必须保持“左侧固定侧边栏，右侧居中主显示区”的严谨排版。
- **核心功能**：系统包含三个高度定制的 AI 模式：
  1. **✨ 全能助手**：处理常规业务与日常流程。
  2. **📚 知识教练**：极具特色的沉浸式培训平台。要求通过“实战航线 -> 客户背景 -> 练习科目”的**三层串联场景筛选**触发，并配有独立的“⚡ 实战情报中心”侧边滑动面板用于辅导。
  3. **💡 专家指导**：解析复杂场景，提供深度策略拆解。

## 2. 目前已完成的工作 (Current State)

我们已经开始了从纯 Vue 3 Web 版向 **Uni-app (Vue 3 + Vite)** 版本的跨端迁移，目前大部分核心业务与前端工程已在 `frontend-uniapp` 目录中就位。

1. **工程架构迁移**：搭建了 `frontend-uniapp` 环境（基于 Vite + Vue3），并成功解决本地 H5 代理调试环境的跨域和认证 (401/404) 拦截问题。
2. **核心流式接口打通**：在 `chat.vue` 组件中，成功对接 FastApi 后端的 SSE 流式响应，实现了小易助手的打字机输出效果。
3. **UI 与 PC 适配完美复刻**：
   - 全局重构了 CSS 变量 (`App.vue`)。
   - 重构了 `chat.vue`，使用媒体查询（Media Query）精准还原了老版本 Web 端的严谨架构：大屏状态强制锁定左侧菜单、居中对话框、隐藏移动端汉堡菜单图标、修正了 Logo 不折行等排版细节。
   - 补全了教练模式下的卡片流、实战情报弹窗等全部 UI 逻辑交互。
4. **资源文件就位**：正版“仲易达集团”Logo 已就位于 `/static/zyd_logo.png`。
